# 🤖 WhatsApp Auto-Reply Bot

بوت تلقائي لـ WhatsApp يرد على الرسائل الواردة تلقائياً مع ميزات متقدمة.

## ✨ المميزات

- ✅ **QR Code Scanning** - مسح رمز QR للاتصال
- ✅ **Auto-Reply** - ردود تلقائية ذكية
- ✅ **Keyword Detection** - كشف الكلمات المفتاحية
- ✅ **Arabic Support** - دعم كامل للعربية
- ✅ **Message Logging** - تسجيل جميع الرسائل
- ✅ **User Tracking** - تتبع المستخدمين
- ✅ **Advanced Commands** - أوامر متقدمة

## 📋 الأوامر المتاحة

| الأمر | الوصف |
|------|-------|
| `القائمة` | عرض جميع الأوامر |
| `الوقت` | عرض الوقت الحالي |
| `التاريخ` | عرض تاريخ اليوم |
| `ساعات العمل` | ساعات العمل |
| `الدعم` | التحدث مع الدعم |
| `حالتي` | معلومات الحساب |
| `عن` | معلومات البوت |

## 🚀 البدء

### المتطلبات

```bash
Node.js 14+
npm أو yarn
```

### التثبيت

```bash
# استنسخ المستودع
git clone https://github.com/911houssem/Best.git
cd Best

# ثبت الحزم
npm install
```

### التشغيل

```bash
# تشغيل البوت الأساسي
npm start

# أو البوت المتقدم
node advanced-bot.js

# تطوير مع auto-reload
npm run dev
```

## 📱 كيفية الاستخدام

1. قم بتشغيل البوت
2. سيظهر QR Code في الطرفية
3. افتح WhatsApp على هاتفك
4. اذهب إلى الإعدادات > الأجهزة المرتبطة > ربط جهاز
5. اسح رمز QR
6. انتظر جاري المصادقة
7. البوت جاهز! 🎉

## 🔧 التخصيص

### إضافة ردود جديدة

في `bot.js`:

```javascript

  'كلمة مفتاحية': 'الرد المطلوب',
  'مرحبا': 'مرحباً بك!'
};
```
